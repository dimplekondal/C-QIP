# C-QIP
Assessing a Multicomponent Quality Improvement Strategy for Chronic Care of Cardiovascular Diseases in India: the c-QIP randomized feasibility trial
The stata codes contain all the information on 
1. How the variables were recoded for analysis
2. How the GDMT definitions were created
3. How the dataset was modified for ITT analysis
4. Programs for GEE models
5. Calculation of scores
6. Sub-group analysis
7. IPTW analysis
